# AMUN2023 analysis pipeline

## Overview

This repository contains seven R scripts for analysing 16S and 18S rRNA gene amplicon sequencing data from water samples collected in the eastern Canadian Arctic during Leg 2 (August-September) and Leg 4 (October) of the 2023 CCGS Amundsen expedition. Input data, supporting files, and analysis outputs are available as a 7z archive on [CanWIN](https://canwin-datahub.ad.umanitoba.ca/data/en/project/micb-amun2023). The complete collection on [Google Drive](https://drive.google.com/drive/folders/1ki3yW1-yE-W7HCAZRh4MeBzsJ4weOFR1) includes everything in the archive plus optional PR2 reference files, raw BLAST results, and higher resolution bathymetry.

## Repository structure and purpose

Provided on GitHub:

| Script | Purpose |
| --- | --- |
| `1A_META.R` | Compile sampling and environmental data, calculate derived variables, and prepare NCBI submission metadata. |
| `2A_TAX.R` | Clean 16S taxonomy (SILVA), load PR2-based 18S assignments, and prepare original and non-rare ASV tables. |
| `3A_CLUS.R` | Cluster samples and ASVs, identify bioindicators, and draw heatmaps and dendrograms. |
| `4A_PLANKT.R` | Calculate Shannon diversity, compare diversity among sample clusters, and summarize major taxonomic groups. |
| `5A_INDIC.R` | Plot prevalent eukaryotic and prokaryotic bioindicators across sample clusters. |
| `6A_ENV.R` | Draw maps, compare environmental properties among sample clusters, assess associations between Shannon diversity and environmental variables, and export supplementary tables and taxonomic summaries. |
| `7A_dbRDA.R` | Assess environmental and eukaryote-prokaryote associations in CL3-CL6 using dbRDA and variation partitioning. |

Provided in the data archive:

- `CTD/`: CTD bottle records and sampling logs.
- `DNA/`: processed 16S/18S ASV tables, classifier results, and DNA sampling metadata.
- `EXT/`: supporting files and saved RDS results used or generated by the scripts.
- `OUT/`: figures, tables and submission files, organized by script.

## Setup and usage

Extract the four folders from the data archive into the directory containing the seven scripts, preserving all folder names and internal structures. Set the directory as the R working directory and run **1A -> 2A -> 3A -> 4A -> 5A -> 6A -> 7A**. Individual scripts can run separately when the inputs listed in their headers are available.

The scripts were run with **R 4.6.2** and **RStudio 2026.10.1.239** on 64-bit Windows. Install the packages listed in the script headers beforehand, including **dplyr >=1.2.0**; install `ComplexHeatmap` through Bioconductor. Using the provided saved results, all seven scripts take approximately **8 minutes** on a laptop with an **Intel Core i7-12700H** processor.

Saved PR2 assignments, bioindicator results, and Shannon diversity estimates avoid repeating computationally intensive steps. The corresponding code is retained in commented blocks for reproducing the results during external review or rerunning the analysis if settings change. Rerunning BLAST also requires `Biostrings` and BLAST+ on the system PATH.

In `6A_ENV.R`, `bathy_res <- 4` allows faster plotting. The manuscript maps used `bathy_res <- 0.5`, which requires higher resolution bathymetry that can be downloaded using `marmap::getNOAA.bathy` or obtained from the Google Drive folder linked above.

Use the provided seeds for reproducibility.
